# Codex 余额挂件

一个面向 Codex 桌面版的 Windows 悬浮挂件。它用互动角色和进度条显示 Codex 当前用量，不读取或保存 ChatGPT 登录令牌。

> 当前为 Windows 测试版，需要本机已经安装并登录 Codex 桌面版。

## 当前状态

可运行的 Windows MVP 已完成：

- 读取真实的 5 小时与每周额度。
- 默认每 30 秒刷新，并响应 Codex 主动推送的额度变化。
- 点击刷新按钮或角色可以立即刷新。
- 透明无边框窗口跟随 Codex 主窗口，Codex 最小化或关闭时自动隐藏。
- 拖动卡片顶部可调整挂件相对位置。
- 角色会根据状态切换动作：常态趴伏、刷新时好奇探头、额度充足时开心挥手、低额度时趴睡。
- 待机期间会随机做短暂的小动作，并保留轻微浮动与动作切换动画。
- 像普通 Windows 窗口一样拖动挂件边缘或四角，可在 70%–140% 范围内连续调整整体大小；人物、文本框、字体和进度条等比例缩放。
- 点击右上角设置按钮，可使用 `−` / `＋` 按钮微调或恢复默认大小，不再使用容易跟随窗口移动的滑轨。
- 大小设置会自动保存，下次启动继续沿用。
- 网络或数据服务中断后每 5 秒自动尝试恢复。

## 结论

项目可行。推荐做成一个独立的透明桌面窗口，并让它跟随 Codex 窗口显示、隐藏和移动。

最关键的数据来源是 Codex 官方 `app-server`：

- `account/rateLimits/read`：读取各额度窗口的已用百分比、窗口长度和重置时间。
- `account/rateLimits/updated`：额度变化时主动通知挂件。
- `account/usage/read`：读取 Token 活动汇总和每日统计；它不是金额余额。

这里显示的应叫“剩余用量”或“额度”，不要叫“账户余额”。ChatGPT 订阅的 Codex 用量不是一个固定人民币余额，官方返回的是窗口内的已用百分比。

## 安装与启动

### 环境要求

- Windows 10 或 Windows 11
- Codex 桌面版
- Node.js 22 或更高版本

### 推荐：下载便携版 EXE

普通用户请打开仓库右侧的 **Releases**，下载：

```text
Codex-Balance-Widget-1.1.0-win-x64.exe
```

无需安装 Node.js。确保 Codex 桌面版已经登录，双击 EXE 即可启动。可以把 EXE 放到桌面或任意文件夹。

> Windows 首次运行社区开源软件时，可能显示来源提醒。请只从本仓库 Releases 页面下载，并核对下面提供的 SHA-256。

### 从源码运行

开发者可以克隆仓库并安装依赖：

```powershell
git clone https://github.com/VITAlemontea12138/Codex-Balance-Widget.git
cd Codex-Balance-Widget
npm install
```

安装完成后，双击项目根目录的 `启动挂件.cmd`，或者运行：

```powershell
npm start
```

关闭挂件时，点击额度卡片右上角的 `×`。

## 单独检查额度

如果只想在终端检查额度、不打开桌面挂件，可以运行：

运行：

```powershell
npm run check
```

成功后会看到类似：

```text
Codex 用量窗口：
- codex 主窗口（5 小时）：已用 25%，剩余 75%，重置 2026/9/20 18:00:00
- codex 次窗口（1 周）：已用 40%，剩余 60%，重置 2026/9/24 08:00:00
```

## 隐私与数据来源

- 额度数据来自本机 Codex 官方 `app-server`。
- 不读取浏览器 Cookie。
- 不复制或保存 ChatGPT 登录令牌。
- 不会把用量数据上传到第三方服务器。

## 当前架构

```text
Codex 官方 app-server
        │
        ├─ 额度百分比、重置时间
        └─ Token 活动统计
        │
本地数据服务（只在内存中处理）
        │
透明桌面悬浮窗
        ├─ 角色图片 / 动画
        ├─ 5 小时额度
        ├─ 每周额度
        └─ 低额度提醒
```

### 暂不支持

- 人民币余额：ChatGPT 订阅没有可直接换算的固定金额余额。
- 修改 Codex 安装目录或注入网页：升级后容易失效，也有安全风险。
- 读取浏览器 Cookie 或复制登录令牌：没有必要。
- 开机启动、静音和提醒阈值设置。
- 复杂账本、皮肤编辑器和音频裁剪。

## 技术路线

推荐使用 Electron：开发速度快，透明窗口、托盘、拖拽和动画都容易实现。Windows 窗口跟随需要一个很小的原生辅助模块来定位 Codex 主窗口。

如果更在意安装包体积，可以后续改成 Tauri；但第一版会多出 Rust 学习和构建成本，不适合先验证产品。
